# 配置说明

## app.env.example

主要定义：
- 项目名
- 默认目标主机
- Runtime 目录
- Core 目标版本
- ACME 和导出默认值

这里的 `ACME_EMAIL` 必须替换成你自己的邮箱。

## targets.yaml

定义服务器清单：
- `id`
- `name`
- `region`
- `role`
- `ssh_host`
- `ssh_user`
- `ssh_auth`

公开仓库里只保留示例目标，不放真实机器。

## nodes.yaml

定义节点矩阵：
- 协议
- 监听端口
- 目标主机
- 导出分组
- 所需 secrets 引用

## outbounds.yaml

定义出口：
- `direct`
- `blocked`
- `vps-v4`
- `vps-v6`
- `residential-static`
- `residential-dynamic`

公开仓库只保留占位或演示数据，不放真实住宅地址和账号。

## routing.yaml

定义域名组到出口的映射。

示例里保留了这些思路：
- OpenAI 走住宅
- Anthropic 走住宅
- Google AI 走住宅
- 普通 Google 走 VPS 直出

## secrets.env.example

这里放所有敏感值的占位符：
- UUID
- 密码
- 私钥
- 证书路径
- 住宅代理账号

真实环境请创建：

```bash
cp deploy/config/secrets.env.example deploy/config/secrets.env
```

然后填写真实值。

## acme.yaml

这里只提供 ACME 结构样例。

实际使用时，每个人都应当：
- 使用自己的域名
- 使用自己的 ACME 邮箱
- 按自己的环境决定 `standalone` 或 `dns`
- 如果使用 DNS challenge，填写自己的 DNS API 凭据
