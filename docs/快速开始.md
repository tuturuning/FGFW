# 快速开始

## 1. 克隆仓库

```bash
git clone https://github.com/tuturuning/FGFW.git
cd FGFW
```

## 2. 检查示例配置

先看这些文件：
- `deploy/config/app.env.example`
- `deploy/config/secrets.env.example`
- `deploy/config/targets.yaml`
- `deploy/config/nodes.yaml`
- `deploy/config/outbounds.yaml`

注意：
- 你必须换成自己的域名
- 你必须填写自己的 `ACME_EMAIL`
- 如果你走 DNS challenge，你必须填写自己的 DNS API 凭据
- 不能沿用仓库示例里的占位值

## 3. 校验脚手架

```bash
./deploy/install.sh validate
```

## 4. 打开菜单

```bash
./deploy/install.sh menu
```

首页会显示：
- 脚本版本
- 服务器信息
- Core 版本
- 运行状态

## 5. 常用命令

```bash
./deploy/install.sh menu
./deploy/install.sh validate
./deploy/install.sh render
./deploy/install.sh apply --target demo-sg
./deploy/install.sh export
```

## 6. 生产使用前必须替换

- 目标主机 IP
- SSH 认证方式
- 域名
- UUID / 密码 / 私钥
- 住宅代理账号
- ACME 邮箱和 DNS API 凭据

## 7. 证书规则

别人部署时，证书必须自己申请。

仓库只提供：
- ACME 配置样例
- challenge 结构
- 证书路径约定

仓库不提供：
- 可直接复用的证书
- 共享 ACME 账号
- 共享 DNS API token
